# MathEconLib website

Source of the MathEconLib landing page, served with GitHub Pages from the root of `main`.

- `index.html` is the whole site for now: one static page, no build step.
- Edit it directly and push; GitHub Pages redeploys within a minute or two.
- Content mirrors the `auctionlib` README and CONTRIBUTING guide. Placeholders to fill are marked in amber italics on the page (search for `class="placeholder"`).

If the site grows past a single page, the plan is to move to Eleventy (with either GitHub Pages or Cloudflare Pages as the host) while keeping the same URL.
